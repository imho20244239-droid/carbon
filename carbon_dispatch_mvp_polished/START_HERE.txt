碳算智调 MVP｜启动与演示入口（精修版）
==========================================

一、首次启动
1. 解压工程包。
2. 在工程目录打开终端。
3. 执行：pip install -r requirements.txt
4. 执行：python -m streamlit run app.py

Windows 也可在安装依赖后双击 run_windows.bat。

二、赛前自检
python smoke_test.py
python validation_evidence_test.py

两项都显示 PASSED 后，再启动 Web 页面。

三、推荐3分钟现场演示
01 运行总览
→ 02 智能调度（72批基准任务，碳价0.25，真实点击求解）
→ 04 策略比较（五类策略；有时间再做9点权重扫描）
→ 06 技术验证（只讲“有效—机制—稳健—规模”证据链）

四、追问时再展示
03 24h调度态势：解释“去哪里算、什么时候算”
05 压力测试：推荐“需求冲击｜1.30×”或“高碳价｜1.00元/kg”
07 参数与数据说明：回答数据来源与仿真边界

五、现场故障恢复
左侧点击“恢复基准场景”，可清除交互求解状态并回到公开校准基准结果。

六、必须保持的口径
- 当前为公开参数校准 + 情景仿真 Web 原型。
- 61.13%是调度碳指标相对下降，不直接等于真实减碳率。
- Monte Carlo 是50组随机运行情景，不是50家企业。
- 8–20节点规模测试为复制扰动情景，不是真实新增数据中心。
- 16/20节点设置5秒时限，不能表述为5秒严格全局最优。

证据来源对应：见 EVIDENCE_MAP.md
